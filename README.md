# Fundit-Security

라이브 커머스형 리워드 펀딩 서비스 Fundit의 보안팀(SAST·DAST·인프라 점검) 산출물을 모아두는 레포입니다.

## 구성

- `sast/` — 정적 애플리케이션 보안 테스트(SAST) + 의존성 점검(SCA). CodeQL, Semgrep, OWASP Dependency-Check로 구성되며, 현재는 Fundit-backend를 주 대상으로 스캔하고 있습니다.
- `dast/` — 동적 애플리케이션 보안 테스트(DAST).
- `infra-audit/` — 인프라 보안 점검.

지금은 Fundit-backend를 주 대상으로 시작했지만, 필요에 따라 프론트엔드나 다른 서비스, 외부 오픈소스, 컨테이너·인프라 코드(IaC) 점검 등으로 범위가 넓어질 수 있습니다.

## 동작 방식

이 레포는 대상 서비스의 기존 CI나 개발 흐름에 영향을 주지 않도록 독립적으로 구성했습니다. GitHub Actions에서 `actions/checkout`으로 대상 레포지토리를 매 실행마다 읽기 전용으로 가져와 스캔하는 방식입니다. 트리거는 PR 단위가 아니라 스케줄(주기적 재스캔) 기반이고, 나중에 필요해지면 워크플로를 대상 레포지토리 쪽으로 직접 통합하는 것도 검토할 수 있습니다.

## 결과 전달

발견된 사항은 정리된 보고서(`sast/reports/` 등)로 전달하는 구조입니다. 오탐은 걸러내되 심각도와 상관없이 확인된 사항은 모두 담고, 우선순위가 높은 항목을 문서 맨 위에 배치하는 식으로 정리합니다. 추후 논의에 따라 변경될 수 있습니다.
